# Birthday Website ❤️

## Quick setup
1. Open this folder in VS Code.
2. Replace `[HER NAME]` in `index.html`.
3. Add your photos to `assets/photos/` using the names shown in the HTML comments.
4. Add your song as `assets/music/birthday-song.mp3`.
5. Edit the personal messages in `index.html`.
6. Open `index.html` in a browser (VS Code Live Server is recommended).

## Photo slots
photo01.jpg through photo06.jpg + final photo placeholder.

The current placeholders intentionally do not contain fake photos.
